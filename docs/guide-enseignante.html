Guide enseignante

Bienvenue sur votre espace pédagogique en ligne. Ce guide vous explique en quelques minutes comment partager un quiz, imprimer une fiche, consulter les résultats, et plus tard, comment ajouter de nouveaux contenus.

1. Vue d'ensemble de la plateforme

La plateforme est accessible publiquement à l'adresse : lyceefrancaisdetananarive.github.io/anglais/

Elle est organisée en trois grandes parties :

  • Le tableau de bord : page d'accueil avec les statistiques et les liens vers chaque niveau.
  • Les pages de niveau : 6e, 4e, 3e, 1re euro, Terminale, NON SI, LCE — chacune liste les séquences disponibles.
  • La bibliothèque PDF : toutes les fiches d'activité prêtes à imprimer (mise en page AEFE-Marque État).
À retenir : tous les contenus sont publics. N'importe qui peut visiter la plateforme et passer un quiz. C'est volontaire : les élèves n'ont pas besoin de compte ni de mot de passe pour participer.

2. Partager un quiz à une classe

Chaque quiz a sa propre URL stable. Il vous suffit de copier-coller cette URL et de la donner à vos élèves (par mail, Pronote, ENT, ou Padlet).

  1. Ouvrez le quiz que vous voulez partager (par ex. depuis le tableau de bord).
  2. Copiez l'URL dans la barre d'adresse de votre navigateur (ex. …/quiz/3e/street-art.html).
  3. Envoyez ce lien à vos élèves par le canal habituel (Pronote, mail de classe, etc.).
  4. Demandez-leur de saisir leur prénom, leur classe, et — facultatif — leur adresse mail s'ils veulent recevoir leur correction.
Astuce : vous pouvez aussi imprimer un QR code de l'URL (via qr-code-generator.com) et le projeter en classe. Les élèves le scannent depuis leur téléphone et accèdent au quiz instantanément.

3. Consulter les résultats des élèves

Chaque fois qu'un élève termine un quiz et clique sur « Envoyer mes résultats », deux choses se passent automatiquement :

  1. Une nouvelle ligne est ajoutée à la feuille Google Sheets « Plateforme Anglais LFT — Résultats quiz ».
  2. Un e-mail récapitulatif vous est envoyé sur salamo.falimanana@egd.mg avec la note, le détail des réponses et la correction.

Pour voir tous les résultats d'un coup : ouvrez la feuille Sheets partagée :
docs.google.com/spreadsheets/d/1wlyyG8mOdDCf807Wk6FFJ_Tj4aMWfzzuILsO_R9EfJs

La feuille contient une ligne par soumission, avec : date, prénom, classe, score brut, note /20, et le détail JSON des réponses.

Filtrer par classe : sur la feuille Sheets, sélectionnez la première ligne, puis Données → Créer un filtre. Vous pourrez ensuite trier les résultats par classe (3M5, 4M7…), date ou note.

4. Imprimer une fiche d'activité

Toutes les fiches sont au format PDF, en mise en page institutionnelle AEFE (Marque État · décembre 2023). Elles sont prêtes à imprimer en A4 recto-verso.

  1. Ouvrez la bibliothèque PDF.
  2. Cliquez sur « Télécharger la fiche » pour la séquence souhaitée.
  3. Le PDF s'ouvre dans un nouvel onglet ou est téléchargé sur votre ordinateur.
  4. Utilisez Cmd+P (Mac) ou Ctrl+P (Windows) pour lancer l'impression.
  5. Dans les options d'impression, choisissez « A4 », « Recto-verso », et « 100 % » (pas de mise à l'échelle).
Économie de toner : les fiches utilisent un bandeau bleu marine sur l'en-tête et le pied de page. Si votre imprimante consomme beaucoup d'encre, vous pouvez activer l'option « Économie d'encre » ou « Niveau de gris » pour réduire l'usage de couleur. Le rendu reste très lisible.

5. À la fin du projet : désactiver le mode développement

Tant que la plateforme est en phase de mise au point, l'administrateur (Max RAFALIARISON) reçoit en copie tous les e-mails de résultats. C'est une mesure temporaire pour permettre les tests et vérifications.

Quand vous validerez que la plateforme est prête à être utilisée en classe avec les élèves, il faudra désactiver ce mode pour que seuls vous (et les élèves) receviez les e-mails.

  1. Connectez-vous à script.google.com avec le compte max.rafaliarison@egd.mg.
  2. Ouvrez le projet « Plateforme Anglais LFT — Mailer ».
  3. Dans l'éditeur, modifiez la ligne const DEV_MODE = true; en const DEV_MODE = false;
  4. Cliquez sur Enregistrer (Cmd+S).
  5. Cliquez sur Déployer → Gérer les déploiements → ✏️ Modifier.
  6. Dans le menu Version, choisissez « Nouvelle version ».
  7. Description : v3 — Désactivation mode DEV (production).
  8. Cliquez sur Déployer. L'URL ne change pas.
Pas besoin de modifier le code de la plateforme — l'URL de l'Apps Script reste identique, donc tous les quiz continueront à fonctionner. Seul le comportement d'envoi des mails change.

6. Ajouter un nouveau quiz (avancé)

Pour ajouter un nouveau quiz à la plateforme, le plus simple est de dupliquer un quiz existant et de modifier son contenu. La procédure complète est documentée dans le fichier README.md du dépôt GitHub.

En résumé :

  1. Dupliquer un quiz existant (par ex. quiz/3e/street-art.html) dans le dossier de niveau souhaité.
  2. Renommer le fichier (ex. quiz/3e/frankenstein.html).
  3. Modifier le bloc <script> en bas du fichier : changer id, title, level, sequence, et la liste questions.
  4. Ajouter un lien vers ce nouveau quiz dans la page de niveau correspondante.
  5. Pousser sur GitHub : git add . && git commit -m "Ajout quiz Frankenstein" && git push.

Le moteur de quiz supporte 4 types de questions :

  • qcm : choix multiple (une seule bonne réponse)
  • multi : cases à cocher (plusieurs bonnes réponses)
  • vrai-faux : Vrai/Faux
  • saisie : texte libre (la comparaison ignore casse, accents, ponctuation)
Si vous n'êtes pas familière avec Git et GitHub, demandez à Max de pousser les modifications pour vous. Vous pouvez préparer le contenu d'un quiz dans un document texte et le lui transmettre.

7. En cas de problème

La plateforme est conçue pour être robuste, mais en cas de souci :

  • Un quiz ne s'affiche pas : rafraîchissez la page (Cmd+R / F5). Si le problème persiste, vérifiez que vous êtes connecté à internet.
  • Un élève me dit qu'il n'a pas reçu son mail : vérifiez avec lui qu'il a bien saisi son adresse correctement à l'étape d'introduction du quiz. Vérifiez aussi son dossier de spam.
  • Je ne vois pas la nouvelle ligne dans la feuille Sheets : rechargez la feuille (Cmd+R). Si elle est vide, contactez Max — l'Apps Script peut avoir été désactivé.
  • Erreur 403 ou 500 sur la plateforme : contactez Max immédiatement.
